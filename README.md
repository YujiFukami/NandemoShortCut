Windows で常駐し、ホットキーから各種ショートカットを呼び出せるデスクトップアプリです。  
フォルダ作成、URL 起動、日付コピー、ファイル起動、コマンド実行、定型文入力などをキー操作だけで呼び出せます。

開発者ホームページ: https://www.softex-celware.com/

## 主な機能

- グローバルホットキーでオーバーレイを呼び出し
- 1文字キー、2段階キーのショートカット実行
- URL を開く
- ファイルやフォルダを開く
- エクスプローラー上でフォルダ作成
- クリップボードへ日付やテキストをコピー
- テキストの自動入力
- 設定画面からショートカット編集
- キー入力で呼び出しホットキーを登録
- スタートアップ登録、解除
- スタートアップ登録時はタスク スケジューラ経由で最上位の特権を要求
- 二重起動防止

## 動作環境

- Windows 10 / 11
- Python 3.12 系で開発

## 使い方

1. アプリを起動します。
2. 設定した呼び出しキーを押します。
3. 表示されたオーバーレイでキーを押してアクションを実行します。

初期設定では `Pause` キーで起動します。

### 初期ショートカット

- `D`: 今日の日付を `YYYYMMDD` 形式でコピー
- `O → B`: `バックアップ` フォルダを作成
- `O → T`: `テンプレート` フォルダを作成
- `O → O`: `オリジナル` フォルダを作成
- `U → G`: Google を開く
- `U → M`: Gmail を開く

### 設定画面

- システムトレイのメニューから開けます
- オーバーレイ表示中に `S` キー、または `設定` ボタンからも開けます
- 呼び出しキーは `キー入力で変更` から直接入力して登録できます
- スタートアップ登録はタスク スケジューラに登録され、次回ログオン時に高い権限で起動します

## 開発時の起動

依存関係をインストール:

```bash
python -m pip install -r requirements.txt
```

アプリを起動:

```bash
python main.py
```

## EXE ビルド

PyInstaller を使ってビルドします。

```bash
python -m PyInstaller NandemoShortcut.spec --noconfirm
```

生成物:

- `dist/NandemoShortcut.exe`

## 設定ファイル

設定は `config.json` で管理します。  
EXE 実行時は EXE と同じフォルダの `config.json` が使われます。  
開発時はプロジェクト直下の `config.json` が使われます。

## リポジトリに含めないもの

- `開発者用/`
- `build/`
- `dist/`
- `__pycache__/`

個人環境向けの設定はリポジトリに含めず、公開用の初期設定だけを `config.json` に保持しています。
